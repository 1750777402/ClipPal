# 单机版稳定性验证（2026-11-21）

当前阶段先完善单机版，默认 Cargo feature 为 `local`，暂停扩展同步、商业和 AI 功能。

## 本轮修复

- 文件剪贴板统一适配本地路径及 file URI。macOS/Windows 写本地路径，Linux 写 URI；
  入库前还原本地路径，正确处理中文、空格、百分号和井号。保留合法文件名的前后空格。
- 文件识别优先于图片，避免复制文件时把系统提供的预览图保存成截图。
- 单文件夹保存本地引用，删除历史记录不删除目录或其中的文件。
- 剪贴板事件按顺序消费，每次回收处理任务；重复启动不会产生多个消费者。
  系统剪贴板锁在投递有界队列之前释放，退出请求不阻塞桌面事件线程。
- 临时文件不再在 60 秒后无条件删除；剪贴板内容替换后才回收旧临时目录。
  应用退出时保留当前副本，使系统剪贴板仍可使用；下次启动接管当前剪贴板引用。
- 保存设置串行执行，使用同目录临时文件写入、同步及原子替换。
  旧设置缺少新字段时保留已有值，非法保留条数不会使启动清理删除全部记录。
- 修改快捷键先注册新键再注销旧键；新键注册失败保留旧键，后续设置保存失败时恢复旧键。
  减少保留条数后立即执行清理并刷新列表；内部写入错误通过统一错误信封返回安全提示。
- 剪贴板监听和主窗口初始化失败会显式返回启动错误，停止忽略关键初始化失败。
  退出时停止原生监听，再通知事件消费者结束。

常规测试只访问临时数据库与测试文件，不操作系统剪贴板。原生剪贴板测试默认忽略，
仅在明确需要桌面集成验证时执行以下命令。先退出正式 ClipPal 实例，避免正式监听器
采集测试内容；测试临时写入内容并在结束时恢复支持的文本、文件、图片及富文本格式：

```bash
cargo test -p tauri-plugin-clipboard-pal native_clipboard_roundtrip -- --ignored --nocapture
```

本轮已在 macOS 原生桌面会话中执行该测试，验证文件/文本/图片的实际读写，以及
文件与预览图片共存时的类型识别。事件压力测试验证连续 300 个事件顺序处理且不重复。
本轮未改动页面组件或 CSS，前端构建的 CSS/JS 文件内容哈希保持一致。

## 启动与验证边界

调试构建支持 `CLIPPAL_DATA_DIR` 指定隔离数据根目录；正式构建忽略该变量。
桌面测试使用独立应用标识及 `/tmp/clippal-standalone-stability`，不修改正式数据库、
正式设置文件或原有内容加密密钥。启动日志确认数据库、搜索索引和快捷键初始化完成，
并跳过同步后台任务。独立线程采样未发现主线程死锁。

桌面自动化读取临时应用窗口超时，未完成 UI 的完整点击验收。自动粘贴的实际目标恢复、
辅助功能授权、另存为对话框及开机自启，仍需在对应系统上完成手工桌面验收。
临时应用放在 `/tmp` 时，更新器会因符号链接路径限制拒绝检查更新；不将该限制当成
正式安装包验证结论。Windows/Linux 尚未进行原生运行验收。

桌面模块已迁移至 `crates/desktop-tauri/src`；本记录中的设置、IPC、系统能力及生命周期修复均在该包继续维护。`src-tauri` 仅用于生成 context、嵌入资产和启动。

薄壳迁移后额外验证：适配包直接运行 Tauri 官方 mock runtime 的 IPC 注册测试；宿主仍通过实际 `generate_context!` 构建检查原有权限与插件元数据，配置和图标通过参数注入。

## 桌面交互修复补充（2026-11-21）

本轮仅处理自动粘贴权限、目标保存、快捷键设置、开机自启和窗口显隐。
此前列出的大文本搜索、大文件去重/采集和硬链接快照问题继续留待后续。

- 自动粘贴在写入系统剪贴板后、隐藏窗口前检查辅助功能权限。缺少权限时保留窗口和
  已复制内容，使用非阻塞提示说明授权位置；同一时刻只显示一个提示。
  权限提示和另存为对话框共享可重叠的隐藏保护，提示结束不会解除其他对话框的保护。
- 本次会话中，前台属于 ClipPal 时保留上次外部粘贴目标；无法取得前台目标或捕获出错时
  清空旧目标，避免沿用未知目标。复制开始时固定目标快照；等待期间重新唤起窗口，
  会取消尚未发送按键的自动粘贴。目标仍由原来的 PID/句柄校验后恢复。
- 快捷键设置读取返回实际注册状态。启动时注册失败会在设置页提示，保存原组合键也会
  重试注册；非法配置回退默认键时，设置页展示实际注册的键。候选快捷键临时向系统注册
  以检查占用，随后释放，不绑定唤起处理器；释放失败会报告错误并在后续操作前重试清理。
  校验与保存串行执行，录制中/校验中不能保存，关闭录制后忽略迟到的校验结果。
- 自启显示读取系统插件状态，保存时与系统当前值比较，并在写入后核对；失败恢复实际旧
  自启状态和旧快捷键，不使用可能过时的文件配置作为回滚依据。运行期快捷键状态不写入
  配置文件，原有设置 IPC 字段保持平铺。
- 启动、快捷键、托盘设置和重复启动共用窗口唤起路径：捕获外部目标、恢复最小化、显示并
  聚焦。自动启动及第二次带 --autostart 的启动保持后台运行，窗口状态恢复不再接管显隐。
  首次真实失焦即可隐藏；短暂异步延后处理失焦并校验焦点序号，避免迟到事件隐藏已重新
  聚焦的窗口。macOS 托盘只在鼠标释放时切换，并保留按下时的显隐意图；Windows 双击直接
  唤起，不再阻塞后隐藏/重开。关闭主窗口收起到托盘，托盘退出仍结束程序。
- 托盘构建失败不再被忽略；窗口操作错误写入日志。内部异常继续使用统一安全错误响应。

验证结果：cargo check --workspace、前端构建、结构检查、git diff --check 和
cargo tauri build --debug --no-bundle 均通过。桌面适配单机/自建/商业测试分别为
19/25/31 项，全部通过，未修改真实系统自启配置或辅助功能授权。
构建前后的 CSS 在归一化 Vue 作用域和对应动画标识后完全一致，没有修改页面 CSS。

本轮未新增原生 UI 点击验收，不能将自动化测试等同于系统授权成功、重启后确实自启或
Windows 实际焦点恢复。macOS 自启插件通过 LaunchAgent 文件判断注册状态，系统是否
另行禁止后台启动仍需在正式安装位置完成注销/登录验收。

手工验收建议：

1. 在外部编辑器唤起 ClipPal，重复按唤起键后选择记录，确认粘贴回原目标；目标退出后
   再选择记录，应仅保留复制结果，不向其他窗口发送按键。
2. 未授权辅助功能时尝试自动粘贴，应显示单个提示且界面可响应；授权后重试。
3. 选择已被其他应用占用的快捷键应失败并保留原键；正常修改后原键失效、新键唤起。
4. 在应用设置内外修改自启状态后重新打开设置核对；从已安装位置注销/登录，确认后台
   启动且不弹出窗口，随后用托盘和快捷键唤起。
5. 验证首次失焦隐藏、连续托盘点击、最小化后唤起、重复启动、关闭后托盘唤起；打开
   权限提示或另存为对话框时，窗口不应被失焦或托盘切换意外隐藏。

## macOS 标准辅助功能授权（2026-11-21）

原实现只有 AXIsProcessTrusted 检测和应用提示，缺少系统授权请求及设置入口。本轮在
桌面适配层新增 accessibility 模块，使用 Apple SDK 的 AXIsProcessTrustedWithOptions，
选项为 kAXTrustedCheckOptionPrompt + CFBoolean true。FFI 返回值按 SDK 的 Boolean
处理，CoreFoundation 对象使用 RAII；授权请求在主线程执行，页面查询不携带 prompt。

Apple SDK 的 AXUIElement.h 明确说明系统提示异步展示，不改变本次函数返回值。因此
“请求授权”返回 required 不代表拒绝，不提前显示已授权，不阻塞等待，也不重放粘贴。
只有用户主动请求时才触发原生授权提示；应用权限提示另提供“打开系统设置”和“稍后”。
系统设置通过固定的辅助功能页面 URL 打开，不接受前端传入任意 URL。

设置页显示系统真实权限状态，提供请求授权与打开设置按钮。重新聚焦时只刷新权限，
不重载未保存表单；迟到的请求结果不能覆盖更新的检测结果，关闭页面后忽略待回调结果。
权限状态不持久化，不用自动粘贴开关推断授权。权限撤销后的提示依据系统检测，避免匹配
错误文案。辅助功能许可并非由 Info.plist 文案授予，也不需要另外请求管理员权限、
屏幕录制或输入监控来发送粘贴快捷键。

验证：cargo check --workspace、前端构建、结构检查及 diff 检查通过；单机/自建/商业
桌面适配测试分别为 20/26/32 项，全部通过。测试只执行真实权限只读查询，不触发系统
授权提示；官方 Tauri mock IPC 验证了新状态接口。另运行现有前端处理函数验证晚到结果
和关闭页面时的竞态。macOS .app 已构建，并检查原生二进制引用两个 AX 检测/请求符号
及系统选项键、包标识和 plist 合并结果。

应用包验证使用 /tmp 中的临时覆盖配置，仅关闭更新产物生成：本机没有更新包签名私钥，
首次构建在 .app 生成后于更新产物签名失败；验证配置下完整打包成功，正式发布配置未变。

尚未执行真实点击授权、拒绝后重试、撤销权限再粘贴的 UI 验收。最终验收必须使用安装
位置固定的 ClipPal.app：请求授权 → 在辅助功能中启用 ClipPal → 回到应用检查已授权 →
切回目标编辑器并重新唤起 ClipPal 粘贴。若系统状态未更新，可退出重开；换签名/换构建
或移动调试包可能使旧授权不再适用，必要时在设置里移除旧项再添加当前应用。正式发行
应保持 Bundle ID 与代码签名身份稳定，不把 cargo test 或裸可执行文件的权限视为已安装
应用的授权结果。
