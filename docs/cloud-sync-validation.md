# 云同步联调记录

验证日期：2026-11-25～2026-11-26。

## 验证结论

真实 Rust 同步客户端分别通过 HTTPS 和调试构建的回环 HTTP 连接 Spring Boot 4.2 / JDK 21 服务端，并使用 Docker 中的 MySQL 8.4。两种连接方式的核心文本同步流程均通过本机端到端验证。HTTP 模式使用普通内嵌 Tomcat，不生成证书、不启用服务端 SSL。

早期协议测试直接调用正式的采集服务、持久化队列、同步会话、HTTP/HTTPS 传输、SSE 解析和 SQLite 回放；每个模拟设备使用独立的临时数据库。结果不能代替两台实体设备、生产域名证书及反向代理部署的验收。

## 真实桌面联调

用 `cargo dev-sync` 和 IDEA 启动日常使用的客户端、服务端，再运行 `python3 scripts/test-cloud-sync.py`。脚本通过系统剪贴板写入文本，核对日常 SQLite 和服务端已提交的 MySQL 变更，等待客户端推进游标并确认待上传动作。测试记录保留在同一份历史里。 [本地同步联调](local-sync-development.md#5-自动验证)

2026-11-26 在 macOS 使用日常数据库实测通过。样例 `ClipPal 云同步联调 9dce33412675` 写入本地 SQLite（记录 ID `36`），服务端返回 MySQL 已提交的同步序号 `16`。客户端已推进游标并确认上传队列中的该条动作。
